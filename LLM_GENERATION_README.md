# LLM-генерация ответственных лиц

Эта функциональность добавляет возможность автоматического выбора ответственных лиц для элементов IFC модели с использованием внутренней LLM и MCP инструментов.

## Что было добавлено

### 1. Модифицированный генератор `RUS_PersonResponsibleForOperation`

**Файл:** `nodejs-server/data-generators.js`

- Генератор теперь принимает параметр `globalid`
- При наличии `globalid` отправляет запрос к внутренней LLM
- LLM анализирует IFC элемент через MCP инструменты и выбирает подходящую должность
- При ошибке или отсутствии `globalid` использует случайный выбор (fallback)

### 2. Функция массовой генерации

**Функция:** `generatePersonResponsibleWithLLM(filename)`

- Принимает параметр `filename` для подключения к базе данных
- Получает все `globalid` из базы данных
- Проверяет каждый `globalid` на `undefined` перед обработкой
- Для каждого валидного элемента обрабатывает через LLM
- Добавляет задержки между запросами (1 секунда)
- Возвращает результаты для всех элементов

### 3. API endpoint

**Endpoint:** `POST /generate-person-responsible-llm`

**Параметры:**
```json
{
  "fileName": "имя_модели"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Массовая генерация завершена",
  "totalProcessed": 150,
  "successCount": 145,
  "errorCount": 5,
  "errors": ["globalid1: error message"]
}
```

### 4. Тестовый скрипт

**Файл:** `nodejs-server/test-llm-generation.js`

Для тестирования функциональности на небольшом количестве элементов.

## Как использовать

### Через API

```bash
curl -X POST http://localhost:4000/generate-person-responsible-llm \
  -H "Content-Type: application/json" \
  -d '{"fileName": "your-model-name"}'
```

### Через скрипт

```javascript
// Массовая генерация
const { generatePersonResponsibleWithLLM } = require('./data-generators');
const results = await generatePersonResponsibleWithLLM('model-name');

// Прямой доступ к генератору
const { dataGenerators } = require('./data-generators');
const result = await dataGenerators['RUS_PersonResponsibleForOperation'](globalId);

// Через универсальную функцию с параметрами
const { generateDataByCode } = require('./data-generators');
const result = await generateDataByCode('RUS_PersonResponsibleForOperation', globalId);
```

### Через тестовый скрипт

1. Отредактируйте `test-llm-generation.js`, указав правильное имя модели:
   ```javascript
   const testFileName = 'your-model-name';
   ```

2. Запустите тест:
   ```bash
   cd nodejs-server
   node test-llm-generation.js
   ```

## Логика работы LLM

### Промпт для LLM

```
Проанализируй IFC элемент с GlobalId: {globalid}.

Используй MCP инструмент get_ifc_properties для получения данных об этом элементе. 
На основе типа элемента, его свойств и назначения выбери наиболее подходящую 
должность ответственного лица из следующего списка:

{список_должностей}

Верни только название должности без дополнительных объяснений.
```

### Доступные должности

- Главный инженер
- Инженер по эксплуатации  
- Технический директор
- Начальник службы эксплуатации
- Главный механик
- Главный энергетик
- Инженер-механик
- Инженер-электрик
- Инженер по вентиляции и кондиционированию
- Инженер по отоплению
- Инженер по водоснабжению
- Инженер по пожарной безопасности
- Руководитель технической службы
- Специалист по техническому обслуживанию
- Мастер по ремонту оборудования
- Начальник отдела эксплуатации

## Важные замечания

1. **Скорость:** Локальная LLM работает медленно, процесс может занять значительное время
2. **Задержки:** Между запросами добавлена задержка в 1 секунду для предотвращения перегрузки
3. **Fallback:** При ошибках LLM используется случайный выбор должности
4. **Логирование:** Все операции логируются в консоль для отслеживания прогресса

## Структура данных

Каждая должность содержит список сотрудников с фамилиями и инициалами:

```javascript
'Главный инженер': [
  'Иванов А.В.', 'Петров С.М.', 'Козлов В.И.', 'Морозов Д.А.'
]
```

Итоговый формат: `"Фамилия И.О., Должность"`

Пример: `"Иванов А.В., Главный инженер"`
