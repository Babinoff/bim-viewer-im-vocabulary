# Генератор RUS_PersonResponsibleForOperation с поддержкой IFC типов

## Описание

Генератор `RUS_PersonResponsibleForOperation` был модифицирован для поддержки обработки элементов по IFC типу. Теперь можно указать тип IFC элементов (например, `IFCLIGHTFIXTURE`) и генератор автоматически найдет все элементы этого типа и сгенерирует для них данные об ответственных лицах.

## Использование

### 1. Через веб-интерфейс

В поле `commandInput` введите команду в формате:
```
RUS_PersonResponsibleForOperation IFCLIGHTFIXTURE
```

Где:
- `RUS_PersonResponsibleForOperation` - название генератора
- `IFCLIGHTFIXTURE` - тип IFC элементов для обработки

### 2. Через API

Отправьте POST запрос на `/add-command` с телом:
```json
{
  "command": "RUS_PersonResponsibleForOperation IFCLIGHTFIXTURE",
  "fileName": "your-model.ifc"
}
```

### 3. Программно

```javascript
const { generateDataByCode } = require('./data-generators');

// Генерация для всех элементов типа IFCLIGHTFIXTURE
const results = await generateDataByCode('RUS_PersonResponsibleForOperation', null, 'IFCLIGHTFIXTURE');

// Генерация для конкретного globalId
const result = await generateDataByCode('RUS_PersonResponsibleForOperation', 'specific-global-id');
```

## Поддерживаемые IFC типы

Генератор может работать с любыми IFC типами, например:
- `IFCLIGHTFIXTURE` - осветительные приборы
- `IFCPUMP` - насосы
- `IFCFAN` - вентиляторы
- `IFCVALVE` - клапаны
- `IFCFLOWSEGMENT` - сегменты трубопроводов
- `IFCFLOWTERMINAL` - терминалы потоков
- И другие...

## Логика работы

1. **Получение списка элементов**: Генератор использует MCP инструмент `list_ifc_entities` для получения всех элементов указанного типа
2. **Обработка каждого элемента**: Для каждого найденного элемента:
   - Получаются свойства элемента через `get_ifc_properties`
   - Анализируется тип и название элемента
   - Определяется, является ли элемент инженерным оборудованием
   - Выбирается подходящая должность ответственного лица
   - Назначается конкретный сотрудник
3. **Обновление базы данных**: Результаты сохраняются в колонку `RUS_PersonResponsibleForOperation`

## Должности ответственных лиц

Генератор использует следующие должности:
- Главный инженер
- Инженер по эксплуатации
- Технический директор
- Начальник службы эксплуатации
- Главный механик
- Главный энергетик
- Инженер-механик
- Инженер-электрик
- Инженер по вентиляции и кондиционированию
- Инженер по отоплению
- Инженер по водоснабжению
- Инженер по пожарной безопасности
- Руководитель технической службы
- Специалист по техническому обслуживанию
- Мастер по ремонту оборудования
- Начальник отдела эксплуатации

## Примеры ответов

```
"Иванов А.В., Главный инженер"
"Соболев А.Г., Инженер-электрик"
"Данилов Е.В., Инженер по вентиляции и кондиционированию"
"Не требуется" (для элементов, не являющихся оборудованием)
```

## Примечания

- Генератор включает задержки между запросами к LLM для предотвращения перегрузки
- В случае ошибки используется fallback к случайной генерации
- Все операции логируются в консоль для отладки
- Текущая версия использует заглушку для MCP вызовов (требуется доработка интеграции)
