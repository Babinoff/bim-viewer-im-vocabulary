# Интеграция BIM-моделей с расширенными данными через SQLite и веб-вьюверы

## MVP системы
Минимально жизнеспособный продукт (MVP), объединяющий BIM-модели (формат IFC) с дополнительными данными из SQLite для:  
✅ **Совместной передачи** (IFC + SQLite в одном пакете)  
✅ **Редактирования данных** через веб-интерфейс  
✅ **Просмотра** модели с расширенной информацией  
✅ **Интеграции с локальными LLM** для автоматического анализа элементов  
✅ **Поддержки MCP (Model Context Protocol)** для расширенного взаимодействия с IFC данными  
🔗 Связь реализована через `GlobalID` элементов без модификации исходного IFC-файла.

## Основные компоненты системы

### 1. Веб-платформы (IFC.JS, Tangl viewer)

### 2. Бекенд Node.js с генерацией SQLite-хранилищ

### 3. Интеграция с локальными LLM
**Новая функциональность:** Автоматический анализ IFC элементов с использованием локальных языковых моделей.

**Возможности:**
- Автоматическое назначение ответственных лиц на основе типа и свойств элементов
- Интеллектуальный анализ инженерного оборудования
- Поддержка команд через веб-интерфейс (например, "заявка [текст]")
- Потоковая обработка ответов LLM в реальном времени

**Поддерживаемые модели:**
- Qwen 3-8B (техническая модель)
- DeepSeek R1 (продвинутая модель)

### 4. MCP (Model Context Protocol) интеграция
**Новая функциональность:** Расширенное взаимодействие с IFC данными через стандартизированный протокол.

**Компоненты:**
- **Bonsai MCP Server:** Доступ к IFC данным через Blender/IfcOpenShell
- **SQLite MCP Server:** Прямое взаимодействие с базой данных
- **MCP Client Tools:** Инструменты для работы с IFC свойствами и геометрией

**Доступные инструменты:**
- `get_ifc_properties` - получение свойств IFC элементов
- `get_ifc_project_info` - информация о проекте
- `query_data` - SQL запросы к базе данных
- `populate_vocabulary_with_random_values` - заполнение тестовых данных 

### 5. Описание полей тестовой таблицы 
Параметры взяты из ПНСТ 909-2024

| **Поле**                           | **Тип** | **Описание**                                                                 |
|-------------------------------------|---------|-----------------------------------------------------------------------------|
| `globalid`                          | TEXT    | Уникальный идентификатор элемента в IFC-модели (`GlobalID`). Обязательное поле, используется для связи с BIM-объектом. |
| `expressID`                         | INT     | Идентификатор объекта для IFC.js (числовой). |
| `vocabulary`                        | TEXT    | Тестовое поле для экспериментов и дополнительных данных. |
| `RUS_DivisionNumber`                | TEXT    | Номер раздела/позиции по российскому классификатору (например, ГОСТ или СПДС). |
| `RUS_StartDatePlan`                 | TEXT    | Плановая дата начала работ (формат: `YYYY-MM-DD` или произвольная строка). |

| `RUS_EndDatePlan`                   | TEXT    | Плановая дата завершения работ. |

| `RUS_ElementCode`                   | TEXT    | Код классификатора элемента. |
| `RUS_OperationTemperatureRange`     | TEXT    | Диапазон рабочих температур для оборудования. |
| `RUS_PersonResponsibleForOperation` | TEXT    | Ответственное лицо за эксплуатацию (ФИО и должность). |

| `RUS_OverhaulDate`                  | TEXT    | Дата последнего/планового капитального ремонта. |
| `RUS_SpareParts`                    | TEXT    | Информация о запасных частях и комплектующих. |
| `RUS_EquipmentCode`                 | TEXT    | Код оборудования в системе учета. |

## Настройка и запуск LLM интеграции

### Требования
- Локальный LLM сервер (например, Open WebUI) на порту 9090
- Python окружение с установленными MCP серверами
- Node.js сервер с поддержкой WebSocket

### Переменные окружения
Создайте файл `.env` в директории `nodejs-server`:
```env
WEBUI_TOKEN=your_api_token_here
MISTRAL_API_KEY=your_mistral_key_here
```

### Запуск MCP серверов
```bash
# Запуск MCP Orchestrator
cd mcp
.\run_mcpo.bat

# Или запуск отдельных серверов
cd mcp/sqlite
uv run server.py

cd mcp/bonsai
uv run bonsai_mcp_client_tools.py
```

### Запуск Node.js сервера
```bash
cd nodejs-server
npm install
npm run dev
```

### Использование в веб-интерфейсе
1. Откройте BIM Viewer
2. Загрузите IFC модель
3. Используйте команды:
   - `"заявка [текст заявки]"` - отправка произвольного запроса к LLM
   - Кнопка "LLM Start" - автоматический анализ "опасных" элементов
   - Кнопка "LLM Log" - просмотр логов взаимодействия с LLM

## API для работы с LLM

### Генерация ответственных лиц
```bash
# Массовая генерация с использованием LLM
curl -X POST http://localhost:4000/generate-person-responsible-llm \
  -H "Content-Type: application/json" \
  -d '{"fileName": "your-model-name"}'
```

### WebSocket события
- `request-llm-results` - запрос анализа LLM
- `llm-chunk` - получение частичного ответа
- `llm-complete` - получение полного результата
- `add-command` - выполнение команд (включая заявки)
